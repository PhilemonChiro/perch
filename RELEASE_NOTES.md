## New
- Copy and paste between your Mac and remote desktops: text, formatted text, images and files, both ways
- Clipboard history for remote sessions (Cmd+Shift+V) and paste as plain text (Cmd+Shift+Option+V)
- Drag files into a remote desktop, and drag them back out to Finder
- Files copied on the server are offered with a Download button instead of being copied to your Mac automatically
- Cmd works like Ctrl on remote desktops (Cmd+C, Cmd+V, Cmd+Z, Cmd+arrows); turn it off per connection
- Stop a running query with the Stop button, Esc or Cmd+.
- Scripts with GO run batch by batch, stop at the first error, and show PRINT output in a new Messages tab
- Delete rows straight from the results grid
- Updates now download and install right inside Perch

## Improved
- Each query tab has its own undo history; formatting and commenting can be undone
- Find and replace, line numbers, Cmd+/ to comment, Cmd+D to select the next match
- Autocomplete understands table aliases and suggests snippets and function arguments
- A dropped database connection reconnects on its own
- Passwords managed by password managers are never sent to remote desktops

## Fixed
- After you change a password and sign in successfully, Perch remembers the new one instead of asking every time
